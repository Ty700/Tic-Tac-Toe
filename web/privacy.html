Privacy Policy

Effective: April 26, 2026

TicTacToe is a hobby-scale online tic-tac-toe game. This policy describes what data the iOS app, web client, and game server collect and why. Read it in full — it's short on purpose.

What we collect

Player name

When you create or join a game, you type a name (e.g. "Tyler"). The name is sent to the game server and stored in memory for the duration of your game session only. Names are not persisted to disk and are not linked to any other identifier.

Server access logs

The server writes basic request information to its standard output (request method, path, game ID, the player name supplied with the request). These logs are written to Docker container stdout and retained only as long as the running container's log buffer. They are not exported to any external system.

Game state

The board state, moves, and turn information for an in-progress game live in server memory. A background "reaper" thread evicts game sessions after a short idle window (10 minutes for unjoined games, 30 minutes for idle active games, 5 minutes for finished games). After eviction, no record of the game remains.

What we do not collect

  • No analytics, advertising, or tracking pixels.
  • No persistent device identifiers, advertising IDs, or fingerprints.
  • No location, contacts, photos, camera, microphone, or health data.
  • No payment information.
  • The iOS app does not use cookies. The web client uses browser sessionStorage to remember your name for the current tab; this is cleared when you close the tab.

Third parties

  • Cloudflare proxies HTTPS traffic to ty700.tech. Cloudflare may process request metadata (IP address, headers) as part of providing TLS termination and DDoS protection. See Cloudflare's privacy policy.
  • Apple distributes the iOS app via the App Store and operates iOS itself. OS-level telemetry is governed by Apple's policies, not this app.
  • No other third parties receive any data from this app.

Your choices

  • To remove your in-progress game session immediately, tap Leave in the iOS app or web client. The server will erase the session.
  • To stop using the iOS app entirely, delete it from your device.
  • For any questions or requests, email T.ScottiBusiness@yahoo.com.

Children

TicTacToe is not directed at children under 13 and does not knowingly collect personal information from children.
